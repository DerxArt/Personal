The universal hook→context→shift→payoff→CTA structure and the emotional-rhythm-mapping (0-3s curiosity spike / 3-15s anticipation / 15-25s tension / payoff) match what's already documented in `research/reels-playbook.md` — this confirms rather than replaces existing structure knowledge. **Niche relevance for @artur.realist (self-improvement/discipline, 16-30 audience, tired of success-theater):**
- **High relevance:** Myth vs Reality format (busting motivation/discipline myths — fits "не ідеальний, а реальний" positioning) and Confession/Storytelling format (showing the real messy process, not a polished win) — see [[instagram-artur-realist-brand]] positioning.
- **Medium, with a caveat:** faceless psychology/facts and motivation-stoicism formats have a useful "fact → reframe" logic, but their typical execution (AI narrator voice, marble/quote aesthetic, no real face) directly conflicts with the account's live, imperfect voice — do not adopt the AI-voice/AI-visual execution, only the structural skeleton if ever useful.
- **Low relevance:** product/e-commerce, science/space, true crime/mystery, finance/B2B, and rankings tables — different niche/audience, don't adapt directly.

**How to apply:** When drafting new Reel scripts, pull the Myth-vs-Reality or Confession skeleton from the full doc as a structural starting point only — every resulting draft still must pass through [[artur-derda-creator-voice]] (written-voice punctuation/style rules) and [[reel-script-natural-delivery]] (spoken delivery must stay loose, not a string of polished one-liners) before it's usable. Never adopt AI-narrator-voice or AI-generated-visual execution styles from this catalog — same rejection reasoning already established in [[ai-content-workflow-claude]] for Higgsfield-style AI visuals. Use the word-count-per-duration table as a mechanical check on script length before filming.
