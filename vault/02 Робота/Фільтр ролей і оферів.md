# Фільтр ролей і оферів

## 10 запитань перед прийняттям роботи або проєкту

1. Чи зрозуміло, який результат очікується від мене за 3 і 6 місяців?
2. Чи маю я свободу обирати спосіб виконання в межах цих цілей?
3. Чи вміє керівник визначати пріоритети й закривати непотрібні задачі?
4. Чи відповідають повноваження моїй відповідальності?
5. Чи буде приблизно 50–65% взаємодії з людьми й достатньо самостійної роботи?
6. Чи є видимий користувач, клієнт або командний результат?
7. Чи зможу я використовувати гіпотези, дані й покращення процесу?
8. Яка реальна рутина ролі й чи готовий я робити її щотижня?
9. Чи залишиться після роботи енергія на сон, стосунки, спорт і блог?
10. Чи обираю я це через рух до бажаного життя, а не лише через страх, провину або престиж?

## Зелені прапорці

- Керівник конкретно пояснює ціль і питає думку про спосіб.
- Команда може назвати пріоритети на найближчі 1–2 місяці.
- Є definition of success і дані для рішень.
- Працівники можуть не погоджуватися з керівником без покарання.
- Роль має scope і процедуру зміни пріоритетів.
- На інтерв'ю чесно говорять про рутину й невдачі.
- Є живий користувач/клієнт і короткий feedback loop.
- Люди регулярно завершують роботу в нормальний час.

## Червоні прапорці

- «У нас немає посад, усі роблять усе».
- «Потрібна людина, яка просто візьме все на себе».
- Керівник не може назвати пріоритети або постійно змінює їх без пояснення.
- Успіх визначається постійною доступністю.
- Команда пишається нічними релізами й овертаймами.
- Відповідальність є, доступу до рішень немає.
- Насправді 80% ролі — cold outbound або конфліктний support.
- Питання про work-life balance викликає зневагу.

## Мінімально прийнятні умови

- Дохід не нижче реального базового бюджету або є чіткий короткий місток до нього.
- Нормальний робочий тиждень без системних овертаймів.
- Чіткий scope і доступний керівник для пріоритизації.
- Поважна командна культура.
- Реальне навчання в роботі.
- Немає регулярної потреби жертвувати сном.

## Де можливий компроміс

- Нижча зарплата на 6–9 місяців заради сильного навчання, якщо базові потреби й подушка захищені.
- Неідеальний office/hybrid format.
- До 60–65% рутини.
- Менша публічність на старті.
- Неідеальна назва посади, якщо реальна робота відповідає профілю.

## Коли сказати «ні»

- Системні 50+ годин без короткої виняткової причини.
- «Усі питання на тобі» без ресурсів і повноважень.
- Потреба фінансувати компанію власною безкоштовною працею.
- Мікроменеджмент або нереалістичні очікування вже на інтерв'ю.
- Рішення приймається лише зі страху, що іншого оферу не буде.

## Швидка scorecard

Оцінити кожен критерій від 1 до 5:

| Критерій | Вага | Оцінка |
|---|---:|---:|
| Свобода й відповідність цінностям | 18% |  |
| Використання сильних сторін | 16% |  |
| Енергетична сумісність і стиль життя | 16% |  |
| Інтерес | 14% |  |
| Фінансовий потенціал | 10% |  |
| Реалістичність входу | 10% |  |
| Стабільність | 6% |  |
| Публічність/визнання | 5% |  |
| Можливість дешевого тесту | 5% |  |

**Критичне правило:** жоден високий середній бал не перекриває три одночасні red flags у межах, культурі та здоров'ї.

## Перегляд після старту

- 30-й день: роль, scope, manager, енергія.
- 60-й день: рутинна реальність, взаємодія, навчання, blockers.
- 90-й день: залишатися, домовлятися про зміни чи починати пошук.
