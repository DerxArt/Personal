## Версія для Reddit

На Reddit потрібна значно пряміша подача, без LinkedIn-рефлексії та персонального брендингу. Головна цінність — конкретна проблема і запит на чесний фідбек.

**Title:**

I keep abandoning every productivity app, so I’m building one that turns tasks into a game

**Post:**

I have the same cycle with almost every productivity tool:

1. Set everything up  
2. Add dozens of tasks  
3. Use it seriously for a few days  
4. Stop opening it  
5. Feel guilty about the abandoned task list

The problem isn’t that I don’t know what needs to be done. The problem is that checking off a task rarely feels rewarding enough to make me come back tomorrow.

So I started building a small web app that treats tasks more like a game.

You earn XP for completing tasks, get more for difficult ones, and can see your progress instead of just watching completed tasks disappear from a list.

It’s still an early version, and I’m trying not to build a huge feature set before confirming that the core idea is actually useful.

I’d love some brutally honest feedback:

- Would gamification make you return to a task manager more often?
- What would make it feel motivating rather than gimmicky?
- Why did you stop using the last productivity app you tried?

I can share a demo in the comments if people are interested.

Для Reddit не потрібні хештеги. Публікувати краще спочатку без прямого посилання, якщо правила конкретного сабреддіта жорсткі щодо self-promotion. Посилання можна дати у відповідь на запит або додати в коментарі, якщо це дозволено правилами.
