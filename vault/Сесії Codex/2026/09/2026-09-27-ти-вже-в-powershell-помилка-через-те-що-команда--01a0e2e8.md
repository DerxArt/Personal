# Ти вже в PowerShell. Помилка через те, що команда вставилась двічі в один рядок (`iexirm`)

> Імпортовано з Codex. Лише текст розмови: виклики інструментів, виводи команд і приховані міркування не включено. Секрети замасковано.

## Артур

Ти вже в PowerShell. Помилка через те, що команда вставилась двічі в один рядок (`iexirm`). Кожен крок — один рядок, вставка один раз.

1. Натисни Ctrl+C, щоб очистити рядок.
2. Скопіюй лише цей рядок, встав один раз, Enter:

```powershell
irm 'https://cursor.com/install?win32=true' | iex
```

3. Дочекайся, поки знову з’явиться `PS C:\Users\derda>`.
4. Тоді цей рядок, один раз, Enter:

```powershell
agent login
```

Увійди в браузері в той самий акаунт Cursor.

5. Потім по черзі:

```powershell
cd C:\Users\derda\Instagram
```

```powershell
agent worker start --name "instagram-pc" --worker-dir C:\Users\derda\Instagram
```

6. Це вікно не закривай. Коли напише, що воркер підключений, напиши мені.

Якщо на кроці 4 `agent` не знаходиться — закрий вікно, відкрий нове PowerShell і почни з кроку 4. Встановлення повторювати не треба.

## Codex

Воркер **`instagram-pc` підключений** і працює з `C:\Users\derda\Instagram`. Термінальну сесію з воркером залишив відкритою.

Після встановлення виявилася несумісність вбудованого Node.js із модулем Cursor Agent. Запустив воркер через наявний сумісний Node.js 22; повідомлення `Worker is now running` отримано.
