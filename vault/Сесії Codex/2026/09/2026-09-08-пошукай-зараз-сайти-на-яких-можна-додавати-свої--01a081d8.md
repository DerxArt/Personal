## Артур

Пошукай зараз сайти, на яких можна додавати свої записи звуку і редагувати. В більшості це повинні бути музичні якісь сайти для створення власної музики, але для того щоб їх можна було відкрити редактор онлайн і безкоштовно.

Моя рекомендація:

1. **BandLab** — найкращий універсальний вибір для початку.
2. **Audiotool** — якщо хочеться створювати біти та електронну музику.
3. **Soundation** — якщо потрібен більш “студійний” інтерфейс.
4. **AudioMass** — якщо треба просто швидко обрізати або почистити запис без реєстрації.

Для першої спроби відкрий [BandLab Studio](https://www.bandlab.com/), натисни **Create → New Project → Import Audio/MIDI**, після чого можна додати власний запис і редагувати його на таймлайні.

## Codex

Так, не ви тупі — **BandLab просто перевантажений кнопками**.

Для вас я б залишив лише два варіанти:

### 1. [Soundtrap](https://www.soundtrap.com/musicmakers) — найкращий для створення музики

Найпростіший сценарій:

1. Відкрити сайт і натиснути **Get started for free**.
2. Створити **New Project**.
3. Додати безкоштовний барабанний або музичний loop.
4. Перетягнути свій MP3/WAV у проєкт.
5. Обрізати, пересунути, змінити гучність і додати ефект.
6. Натиснути **Download/Export**.

Soundtrap має безкоштовні проєкти, прості loops, запис вокалу та імпорт власних аудіофайлів. Частина звуків платна, але почати можна безкоштовно. citeturn6search2turn5search2turn3view6

### 2. [AudioMass](https://audiomass.co/) — якщо треба просто порізати й почистити запис

Там взагалі майже нічого не треба вчити:

- перетягнули файл у вікно;
- виділили непотрібну частину;
- натиснули **Cut**;
- за потреби додали **Noise Reduction**, **Fade** або **Volume**;
- натиснули **Export/Download**.

Він безкоштовний, працює прямо в браузері й не потребує реєстрації. Але це більше редактор записів, а не повноцінний музичний конструктор. citeturn6search0turn6search8

Мій вибір для вас: **Soundtrap**, якщо хочете додати до свого запису музику або біти; **AudioMass**, якщо потрібно лише обрізати, почистити чи зробити голос гучнішим.
