# Я хочу, щоб ти детально дослідив Google, щоб ти зайшов в Google, проаналізував купу сайтів

> Імпортовано з Codex. Лише текст розмови: виклики інструментів, виводи команд і приховані міркування не включено. Секрети замасковано.

## Артур

Я хочу, щоб ти детально дослідив Google, щоб ти зайшов в Google, проаналізував купу сайтів, чи є десь готові бібліотеки, де можна безкоштовно скачати бібліотеку готових скриптів для рілсів, для того щоб навчити штучний інтелект писати якісні скрипти для рілсів.

## Codex

Так, такі матеріали є. Але важливий висновок: я не знайшов однієї великої, чистої й повністю легальної бібліотеки саме готових Instagram Reels-скриптів для комерційного навчання AI. Найкращий результат дасть комбінація кількох джерел.

## Найцінніші датасети для AI

| Джерело | Що всередині | Оцінка |
|---|---|---|
| [TikTok Hooks Fine-tune](https://huggingface.co/datasets/benxh/tiktok-hooks-finetune) | 46 605 рядків: hooks, captions, ніші, перегляди, лайки, коментарі, shares, готові conversation-поля; приблизно 36 MB | Найкращий старт для fine-tuning/RAG. У картці вказано MIT, але походження TikTok-контенту треба перевірити |
| [Shofo TikTok General Small](https://huggingface.co/datasets/Shofo/shofo-tiktok-general-small) | 50 000 TikTok-відео, ASR-транскрипції, captions, hashtags, comments, engagement metrics; приблизно 500 GB | Сильний мультимодальний корпус, але дуже великий і з правовими ризиками |
| [UGC-VideoCap](https://huggingface.co/datasets/openinterx/UGC-VideoCap) | 1 000 TikTok-відео та 4 000 аудіо/відео QA-анотацій | Добре для аналізу відеоструктури, але це більше captioning, ніж готові сценарії |
| [Vript](https://huggingface.co/datasets/Mutonix/Vript) | Приблизно 12 000 відео та 400 000 кліпів; shot type, camera movement, scene content, voice-over | Найближче до повноцінного production-сценарію. Але ліцензія — academic use only, без комерційного використання |
| [YouTube-Commons](https://huggingface.co/datasets/gautijha37/YouTube-Commons) | 22,7 млн транскриптів із 3,15 млн YouTube-відео під CC-BY, близько 45 млрд слів | Найкращий великий корпус із чіткішою ліцензійною базою. Не Reels-специфічний, але можна відфільтрувати короткі відео |
| [TikTok Videos 4B](https://huggingface.co/datasets/kuben-developer/tiktok-videos-4b) | 4,5 млрд записів із captions, тривалістю та engagement-метриками | Не містить справжніх сценаріїв або відео; корисний лише для аналізу популярності. Research/educational only |

## Open-source бібліотеки формул

Це не набори готових повних сценаріїв, але дуже корисні для навчання AI структурі.

- [Vyral Content Skills](https://github.com/vyralcontent/content-skills) — MIT, hooks, scripts, captions, CTA, Reels/TikTok/Shorts.
- [Viral Hooks Skill](https://github.com/rediumvex/viral-hooks-skill) — MIT, 100 hook-формул у Markdown, розділених на 10 психологічних категорій.
- [Creator Futures Reels Script](https://github.com/creator-futures/social-media-skills/tree/main/skills/reels-script) — MIT; формує сценарій у структурі `shot → on-screen text → spoken line → audio → timing`.
- [Instagram Growth Templates 2026](https://github.com/jakeolschewski/instagram-growth-templates-2026) — MIT; містить шаблони Quick-Tip, Day-in-the-Life, Transformation та Trending Audio Reels.

Останній репозиторій краще використовувати як бібліотеку форматів, а не як доказ того, що його твердження про алгоритм Instagram науково підтверджені.

## Що я рекомендую використати

Для першої версії AI-корпусу:

1. Взяти [TikTok Hooks Fine-tune](https://huggingface.co/datasets/benxh/tiktok-hooks-finetune) як основний машинний набір.
2. Додати формули з [Vyral Content Skills](https://github.com/vyralcontent/content-skills), [Viral Hooks Skill](https://github.com/rediumvex/viral-hooks-skill) і [Creator Futures](https://github.com/creator-futures/social-media-skills/tree/main/skills/reels-script).
3. Витягнути структури з PDF-паків: hook, problem, value, proof, payoff, CTA, timing.
4. Створити власний перевірений набір із 200–500 сценаріїв.
5. Зберігати кожен приклад у такому форматі:

```json
{
  "platform": "instagram_reels",
  "language": "uk",
  "niche": "business",
  "goal": "saves",
  "duration_sec": 30,
  "hook_type": "contrarian",
  "hook": "...",
  "spoken_script": "...",
  "on_screen_text": "...",
  "visual_direction": "...",
  "cta": "...",
  "source_url": "...",
  "license": "...",
  "rights_status": "owned_or_permitted",
  "quality_score": 9
}
```

## Важливе питання ліцензій

«Безкоштовно скачати» не означає «можна використати для навчання комерційної моделі».

- MIT-ліцензія стосується вмісту конкретного репозиторію, але не обов’язково всього стороннього TikTok/Instagram-контенту всередині нього.
- CC-BY дозволяє комерційне використання й адаптацію, але вимагає атрибуції. Це підтверджують [Creative Commons](https://creativecommons.org/licenses/by/4.0/) і [YouTube](https://support.google.com/youtube/answer/2797468?hl=en).
- CC-BY-NC не підходить для комерційного продукту.
- Vript і TikTok 4B мають research-only обмеження.
- PDF-паки зазвичай дозволяють безкоштовне читання та використання ідей, але не дають явного дозволу на перепродаж або навчання ваг AI.

Мій підсумковий вибір:

- для швидкого старту — **TikTok Hooks Fine-tune**;
- для структури сценаріїв — **Creator Futures + Vyral + Viral Hooks**;
- для production-level розмітки — **Vript**, але лише для досліджень;
- для більш безпечного великого корпусу — **YouTube-Commons із CC-BY та атрибуцією**;
- для готових прикладів — **Synth Studio, Storykit, deAsra, IdeaExplainers**.

Наступним кроком я можу зібрати з цих джерел чисту структуру датасету для навчання AI: відфільтрувати шум, розділити hooks/скрипти/CTA, перекласти потрібну частину українською та підготувати JSONL.
