Для Hermes треба виставити контекст **64K**: Hermes вимагає щонайменше 64 000 токенів, а Ollama на системах із менш ніж 24 ГБ VRAM за замовчуванням може використовувати лише 4K. У PowerShell створи файл `Modelfile` з таким вмістом, а тоді виконай команди:

```text
FROM qwen3.5:4b
PARAMETER num_ctx 64000
```

```powershell
ollama pull qwen3.5:4b
ollama create qwen3.5:4b-64k -f .\Modelfile
```

Потім у `hermes model` вибери **Custom endpoint**: `http://localhost:11434/v1`, модель `qwen3.5:4b-64k`, API key — порожній. Hermes підтримує Ollama як локальний endpoint. [Налаштування провайдера Hermes](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/integrations/providers.md)

За цими характеристиками це має запускатися, хоча швидкість залежатиме від того, скільки пам’яті буде вільно під час роботи. `qwen3.5:9b` може дати кращі відповіді, але для першого запуску Hermes на цій машині я б почав із 4B.

1. Встанови [Ollama для Windows](https://ollama.com/download/windows) і відкрий його.

- **API key:** залиш порожнім
- **Model name:** `qwen3.5:4b-64k`
- **Context length:** `64000`

Ollama має бути запущений, поки працює Hermes. Це потрібне налаштування контексту: Hermes вимагає щонайменше 64K для роботи з інструментами. [Інструкція Hermes](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/integrations/providers.md)
