# Personal OS: PRD 0.1

**Статус:** перша робоча версія за підсумками інтерв'ю 21 жовтня 2026. Підтверджені рішення відокремлені від припущень. Spike по готових ядрах зроблено лише на рівні README, без запуску.

## Продукт у двох реченнях

Один екран, на якому видно роботу всіх AI-підписок Артура (Claude, ChatGPT, Gemini, Cursor, OpenCode, Grok, локальні моделі), усі задачі та проєкти. Артур кидає задачу в одне поле, а Jev (модель рішень від TypeSafe) обирає, якому AI її віддати, з огляду на можливості кожного AI, залишок квот і контекст з Obsidian-vault.

## Проблема (слова Артура)

1. **Купа вкладок.** Підписок багато, і щоб побачити, що де відбувається, треба перемикатися між мільйоном вкладок. Хочеться бачити активне й непрочитане в одному місці.
2. **Контекст розкиданий** між Notion, Drive, Instagram-папкою, пам'яттю Claude і vault. Потрібне одне місце, з якого можна перейти куди завгодно.
3. **Ручний вибір AI.** Платить за Gemini, майже не користується. Прості запити мають іти туди автоматично.
4. **Повторювані воркфлоу** запускаються руками щоразу.

## Цілі та не-цілі

**Цілі**
- Один екран для всіх AI, задач і проєктів: статус, лог, результат, «потребує тебе».
- Автоматичний роутинг задач через Jev з поясненням вибору та корекцією від Артура.
- Obsidian-vault як спільний Second Brain для всіх AI.
- **$0 доплат**: лише вже оплачені підписки і безкоштовні локальні моделі. Єдине виключення: Jev, оплачений наперед ($5 покриває ~60 000 запитів роутингу).
- Мінімум токенів: статуси, черга, дашборд і розклад працюють кодом, без AI.
- Правки Артура вбудовані в продукт: система вчиться на оцінках.

**Не-цілі**
- Не замінює [[Productivity OS]]. Це окремий проєкт. Personal OS лише показує його (читання) в v0.5.
- Жодних платних API (включно з OpenRouter) у v0. Опційний адаптер для безкоштовних моделей, за замовчуванням вимкнений.
- Жодних автономних дій назовні (лист, пост, повідомлення, видалення) без схвалення.
- Не багатокористувацька система. Не універсальний фреймворк агентів.

## Користувач і середовище

- Один користувач: Артур. Мова інтерфейсу й нотаток: українська.
- Стаціонарний Windows 11 ПК (ASUS), RTX 3060 12 ГБ, 16 ГБ RAM, ~47 ГБ вільно на C:. Акумулятора немає, тож постійна робота реальна.
- Демон живе на цьому ПК. Сон при живленні вимикається. Доступ з телефона через безкоштовний тунель (Tailscale). Якщо ПК вимкнений, задачі стоять у черзі.
- Час на налаштування обмежений; ціль: початкова версія швидко, далі покращення за правками.

## Принципи

1. **Код керує процесом, AI дає судження.** Детерміноване (розклад, квоти, черга, статуси) робить код.
2. **Adopt + glue.** Беремо готове ядро-оркестратор; пишемо лише тонкі унікальні шари. Шлях до власного ядра відкритий.
3. **Тонка v0, швидкі правки.** Спершу платформа, воркфлоу додаємо як «рецепти» з реальних задач.
4. **Дії назовні лише зі схваленням.**
5. **Секрети ніколи не потрапляють у промпти й логи** (паролі, API-ключі, токени).
6. **Прозорість.** Кожен вибір AI має пояснення (ймовірності Jev) і кнопку «не той AI».

## Архітектура

```
 Телефон / браузер (Tailscale)        Дашборд (ядро після spike)
                 \                        /
                  +--- Демон Personal OS ---+
                  |  черга і стан: SQLite    |
                  |  Диспетчер + Router (Jev)|
                  |  Облік квот + бюджет Jev |
                  |  Міст до vault + журнал  |
                  +--+-----+-----+-----+-----+
                     |     |     |     |
                  CLI    Локальні  Браузерні   Ручна
                 адаптери  моделі   скрипти    передача
              (Claude Code, (Ollama)  (ChatGPT фото,  (картка
               Codex, Gemini CLI,      Grok, спостерігач) "зроби сам")
               OpenCode, Cursor CLI)
```

- **Ядро/екран:** готовий open-source оркестратор (див. spike). Те, чого в ньому немає, додаємо шарами.
- **Стан:** SQLite (задачі, запуски, оцінки, квоти, витрати Jev).
- **Знання:** Obsidian-vault (файли). Агенти пишуть лише в Inbox/AI-папку.
- **Мова реалізації тонких шарів:** TypeScript (Node 24 / Bun вже встановлені).

## Роутер на Jev

**Один запит на задачу** (`POST /v1/systemone`, модель `jev-latest`, ~100 мс, ~2000 вхідних токенів: задача + реєстр можливостей + залишки квот; вихідні токени безкоштовні). Питання запускаються паралельно й не бачать одне одного.

| Питання | Тип | Для чого |
|---|---|---|
| Який AI найкращий для цієї задачі | Choice (варіанти з реєстру) | основний вибір, ймовірності для запасного варіанта |
| Потрібен код/файли | Noul | Cursor, Claude Code, Codex |
| Потрібен інтернет/свіжа інформація | Noul | Gemini, Grok |
| Потрібна генерація зображення | Noul | ChatGPT (веб) |
| Довга фонова задача | Noul | ChatGPT/Claude, у фоні |
| Проста довідка | Noul | Gemini або локальна модель |
| Потрібен контекст vault | Noul | чи додавати нотатки в промпт |
| Дія назовні (надіслати/опублікувати/видалити) | Noul | ворота схвалення |
| Складність | Score 0-4 | дешевша модель для простого |

**Правила в коді** (не в Jev): впевненість Choice >= 0.6, інакше картка «потрібне рішення»; AI без квоти пропускається, береться наступний за ймовірністю; `дія назовні > 0.5` вимагає схвалення; Jev недоступний або баланс < $0.5 -> роутер на правилах.

**Бюджет:** $0.042 за 1 млн вхідних токенів. $5 ~ 119 млн токенів ~ 60 000 запитів ~ 3-4 роки при 50 задачах на день. Лічильник береться з поля `usage` у відповідях.

**Принцип реєстру:** Jev не знає сильних сторін конкретних продуктів, тому реєстр передається в `state`. Джерело правди: досвід Артура, не бенчмарки.

**Перевірено на реальному ключі 21.10.2026** (`router/smoke-jev.mjs`, модель `jev-1.13.0`, 5 задач): затримка 345-544 мс, ~2 050 вхідних токенів, ~$0.000086 за запит (тобто $5 це ~58 000 запитів). Приклади:

| Задача | Вибір | Впевненість | Сигнали |
|---|---|---|---|
| Сценарій рілса про дисципліну | claude 0.92 | 0.90 | складність 1.45 |
| «Що таке MCP простими словами?» | gemini 0.98 | 0.97 | is_simple 0.81 |
| Обкладинка для каруселі | codex 0.72 | 0.65 | needs_image 0.75 |
| «Відправ цей лист клієнту» | claude 0.50 | **0.37** | **outward 0.95**: ворота схвалення + картка «потрібне рішення» |
| Рефакторинг модуля + тести | claude 0.78 | 0.73 | needs_code 0.92, складність 2.86 |

Пороги з PRD (впевненість >= 0.6, `outward_action > 0.5`) спрацювали так, як задумано. Реєстр поки чернетковий: у задачі на код Codex отримав лише 0.13, його опис треба уточнити за оцінками Артура.

## Реєстр можливостей AI (чернетка зі слів Артура)

| AI | Режим | Сильні сторони | Примітки |
|---|---|---|---|
| Claude (Sonnet) | CLI (Claude Code, встановлено 2.1.287) | універсал, будь-яка задача, голос Артура | квота береже для складного |
| ChatGPT | веб-скрипт; Codex CLI (не встановлено) | генерація фото, довгі задачі (Luna) | фото лише через веб; Luna потребує уточнення |
| Gemini | **Antigravity CLI `agy`** (Gemini CLI з 18.06.2026 не обслуговує особисті акаунти; `agy` ще не встановлено) | швидкі відповіді, пошук, сценарії | майже не використовується, платиться: пріоритет для простого. Headless: `agy -p "..." --output-format json --model <slug>` |
| Cursor | Cursor CLI (не встановлено; застосунок 3.23.12 є) | багато агентів/ботів одночасно | |
| Grok | веб/CLI | особисті задачі | назва «GrokBot» потребує уточнення |
| OpenCode | CLI 1.19.3 встановлено, **не працює** (`Invalid credential`) | запасний виконавець | знижений пріоритет у v0. Гвардрейл: дозволені лише моделі `*-free` (решта Zen платні за токени) |
| Локальна модель | Ollama 0.40.6, `qwen3.5:4b` (+64k варіант) | безкоштовні прості задачі, fallback-суддя | GPU 12 ГБ дозволяє більші моделі |

Реєстр живе у vault: по нотатці на AI (`сильні`, `слабкі`, `не для`, `приклади`, `ліміти`, `останнє оновлення`). Оновлюється за оцінками.

## Адаптери

| Режим | Що робить | Надійність |
|---|---|---|
| `cli` | запуск агента зі входом через підписку, живий статус, лог, результат | висока |
| `local` | запит до Ollama | висока |
| `browser-watch` | читає вкладки ChatGPT/Gemini/Grok: «генерує», «є непрочитане» (без введення) | середня |
| `browser-control` | скрипт (Playwright) вводить промпт і забирає результат; без AI-агента, тож 0 токенів | низька-середня, ламається при зміні верстки |
| `manual` | картка «передай вручну», промпт у буфері, відкриває вкладку | завжди працює |
| `api/openrouter` | лише за потреби, **вимкнено за замовчуванням** | висока, але платна |

Спостерігач і керування веб-вкладками працюють скриптами. Ризик для акаунтів Артур прийняв усвідомлено 21.10.2026.

## Second Brain (vault)

- **Корінь:** верхній рівень `01 Я ... 09 Перевірити` (рішення від 21.10.2026). Це кураторські нотатки та найсвіжіші імпорти.
- `Personal 2/` не видаляється: це архів сирого матеріалу з дублями. Розбір у Фазі 0 за планом злиття; видалення тільки зі схвалення.
- У корені додається `AGENTS.md` з правилами для будь-якого AI-агента: мова, frontmatter, що можна змінювати, куди писати.
- Агенти пишуть у `Inbox/` (існує `Promotion Inbox`). Перенесення в основні розділи робить Артур.
- **Журнал агентів:** після кожної задачі агент дописує один рядок (хто, що, результат, дата). Інші читають його перед відповіддю.
- Структуровані операційні дані не живуть у markdown: вони в SQLite.
- Запис в OneDrive: атомарно (тимчасовий файл + перейменування), один письменник (демон), кирилиця в шляху враховується.
- Приватність: все `cloud-ok` за замовчуванням. Необов'язковий прапорець `privacy: local-only` у frontmatter.

## Екрани дашборда

1. **Потребує тебе:** невпевнений роутинг, схвалення дій, прострочений вхід, зламаний скрипт.
2. **Активні:** що зараз виконується і хто виконує, статус, лог.
3. **Задачі й проєкти:** уся історія; проєкти з `05 Проєкти`.
4. **Квоти:** залишок по кожній підписці, лічильник Jev, економія.
5. **Журнал:** що зробив кожен AI.
6. **Фідбек:** скринька «що незручно в самій системі».
7. **Швидке поле:** кинути задачу (з телефона теж).

## Фідбек-цикл

- 👍/👎 і одне речення «що не так» на кожній картці.
- «Не той AI, відправити іншому»: виправлення потрапляє в журнал і калібрує реєстр.
- Скринька «Фідбек про систему» дає наступні задачі для доробки.
- Раз на тиждень короткий підсумок: що спрацювало, де помилявся роутер, куди йшла квота.

## Крайові випадки (дефолти)

| Ситуація | Поведінка |
|---|---|
| Jev невпевнений (< 0.6) | картка «потрібне рішення», нічого не відбувається наосліп |
| Квота AI вичерпана | наступний за ймовірністю, запис у журнал |
| Вхід у CLI прострочений | картка «потрібен вхід», без циклів повтору |
| Браузерний скрипт зламався | перехід на `manual`, одне повідомлення |
| Jev недоступний або баланс < $0.5 | роутер на правилах + банер |
| ПК вимкнений | черга; пропущені розклади виконуються один раз |
| Задача зависла | таймаут; не більше одного автоповтору |
| Дія назовні | завжди зі схваленням |
| Конфлікт запису vault | один письменник, атомарний запис |

## Безпека доступу з телефона

Готові оркестратори (зокрема CCC) працюють без логіну: хто дістався до порту, той виконує команди від імені Артура. Тому: демон слухає тільки `127.0.0.1`; доступ з телефона лише через Tailscale (tailnet з власних пристроїв Артура), без Funnel і публічних адрес; обов'язковий PIN або токен на запити ззовні; жодних секретів у логах і промптах.

## Відкриті питання

- Що таке «Luna» (ChatGPT) і «GrokBot»: уточнити назви й можливості.
