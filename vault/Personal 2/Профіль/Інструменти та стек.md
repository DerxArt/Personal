# Інструменти та стек

## Активно згадані у твоїх власних навичках (висока впевненість — навички написані спеціально під них)

- **Notion** — CRM лідів-амбасадорів, нотатки зустрічей, Founder Dashboard, пошук по мітингах
- **Jira + Confluence (Atlassian)** — проєкт Otake.io: баги, задачі, специфікації, Change Request Log
- **Instagram + Claude in Chrome** — ручний/напівавтоматичний аутріч, перевірка DM, коментарі, лайки
- **Apify** — скрейпінг інстаграм-профілів (лідогенерація амбасадорів)
- **Google Sheets** — джерело для перенесення лідів у Notion
- **Figma** — конвертація email-дизайну в HTML для SendGrid
- **Higgsfield** — генерація зображень і відео (інфографіка, UGC-реклама з фото продукту)
- **Google Docs** — контент-бриф для амбасадорів виводиться саме туди
