# Контент і голос

У тебе є ціла лінійка навичок, які пишуть контент "голосом Дерди (Artur'а)" — тобто в системі задокументовано конкретний стиль письма, а не загальний "AI-тон".

## Формати, які ти регулярно готуєш

| Формат | Особливості з опису навички |
|---|---|
| Блог-пост | хук на старті, чіткі заголовки, ключове слово вплетене природно, один CTA — зберігається в `content/` |
| LinkedIn-пост | сильний хук у першому рядку, короткі абзаци, один меседж, м'який CTA |
| Коментар під постом у LinkedIn-стрічці | розмовний тон, "як усна репліка" — саме так описано в навичці |
| Instagram carousel | hook-обкладинка → 5–7 слайдів по одній ідеї → CTA-слайд — зберігається в `social/` |
| Лід-магніт (PDF) | дизайнерська система бренду: жирний червоно-чорно-бавовняний редакційний стиль — зберігається в `content/` |
| Email | окрема навичка спершу вчить твій реальний стиль листування, потім пише драфти в цьому стилі; ніколи не надсилає сама, завжди показує драфт на перевірку |
| Репурпоснутий контент | одне джерело (YouTube-лінк, транскрипт, відео) → блог-пост + email + LinkedIn-пост за один прохід |

## Висновок

Стиль — прямий, розмовний, без зайвої формальності, з одним чітким меседжем на одиницю контенту. Якщо просиш щось написати "твоїм голосом" без додаткових пояснень, орієнтир — саме ця лінійка навичок, а не загальний корпоративний тон.
