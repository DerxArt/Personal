# Бізнес — Otake

Судячи з навичок, встановлених у твоєму акаунті, ти керуєш продуктом **Otake (otake.io)** або щільно залучений до його роботи — приблизно десяток навичок написані спеціально під нього.

## Що це за продукт, наскільки видно

- Схоже на **link-in-bio / booking-сторінку** для інстаграм-креаторів і бізнесів.
- Прямі конкуренти, які згадуються в навичках: **Linktree, hoo.be, Calendly, bio.site**.
- Є фіча бронювання ("Booking") — під неї існує окрема специфікація в Confluence.

## Ambassador-програма

- Пошук інстаграм-креаторів через Apify (публічні, англомовні, з активністю за останній тиждень).
- Фільтр за підписниками, з розподілом по воронках:
  - **5K–15K підписників** → воронка **Barter**
  - **15K+ підписників** → воронка **Paid**
- Перевірка біо на конкурентні лінки (Linktree, hoo.be, Calendly, bio.site) як сигнал якісного ліда.
- Повний цикл аутрічу: warm-up (лайки + живий коментар) → перший бартерний DM → обробка заперечень → активаційні повідомлення після "так" → follow-up після мовчанки → ввічливий вихід після відмови.
- Окрема навичка готує **дзвінок** з креатором: скрейпить профіль, читає DM-переписку, перевіряє нотатки в CRM, підвантажує "Sales Quick Reference" з Confluence і генерує повний скрипт дзвінка + ідеї сторінок.
- Окрема навичка готує **контент-бриф (ТЗ)** для амбасадора: аналізує стиль відео в профілі, тягне фічі продукту з Confluence + сайту, підбирає 5 відеорефересів під стиль креатора, віддає готовий Google Doc.

## Де що зберігається

| Що | Де |
|---|---|
| CRM лідів-амбасадорів | Notion |
| Технічні специфікації (напр. Booking) | Confluence, pageId `54427678` |
| Change Request Log | Confluence, pageId `208633857` |
| Баги, задачі, CR | Jira, проєкт Otake.io |
| Founder Dashboard (звідні нотатки зустрічей + статус спринту) | Notion, pageId `35658af3598f81c8a388d624ed8b086e` |

## Що це говорить про твою роль

Схоже, ти поєднуєш кілька функцій одночасно:

- **Founder / продукт-власник** — існування "Founder Dashboard" і те, що саме туди стікається статус спринту й нотатки зустрічей, натякає, що це або твій дашборд, або ти готуєш його для когось вище.
- **Business Analyst / QA** — є окремі навички для написання BA-документації (з edge cases і альтернативними сценаріями) і генерації тест-кейсів прямо з user story чи Jira-задачі.
- **Growth / Sales** — весь ambassador outreach конвеєр, від пошуку лідів до дзвінка.
- **Контент і маркетинг** — див. [[Профіль/Контент і голос|окремий файл]].
