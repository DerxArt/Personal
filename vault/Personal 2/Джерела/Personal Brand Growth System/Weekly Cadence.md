# Weekly Cadence

> Повний механічний витяг із локального Excel workbook. Формули показано як cached values, коли вони доступні; статуси `Planned` / `Not started` не означають виконання.

| C1 | C2 | C3 | C4 | C5 | C6 | C7 |
|---|---|---|---|---|---|---|
| Тижневий операційний ритм |  |  |  |  |  |  |
| День | LinkedIn | Threads | Instagram | Stories | Аналітика | Правило |
| Понеділок | Пост-історія або урок. | 3 думки з фокусу тижня. | Stories only. | Показати старт тижня, план, настрій. | Зафіксувати тест тижня. | Не починати тиждень без теми. |
| Вівторок | Коментарі в цільових авторів. | 3 threads: 1 питання, 1 теза, 1 факап. | Reel/post про процес. | 10 stories: робота, думки, backstage. | Дивитись replies. | Threads = тестовий полігон. |
| Середа | Пост-думка / провокаційна теза. | 3 threads з реакцією на коменти. | Stories only. | Показати середину тижня і friction. | Занотувати сильні формулювання. | Гостро, але без токсичності. |
| Четвер | Коментарі + підготовка draft. | 3 короткі тести hooks. | Reel/post: урок або міні-історія. | Питання до аудиторії. | Перевірити, що зачепило. | Не шліфувати Threads надто довго. |
| П'ятниця | Optional post: self-review / work lesson. | 3 threads: підсумки, провал, висновок. | Stories only. | Публічний self-review. | Записати best/worst пост. | Відкритість має мати висновок. |
| Субота | Без обов'язкового посту. | 2-3 casual threads. | Optional running/backstage post. | Більше життя, менше роботи. | Легка перевірка метрик. | Людяність теж стратегія. |
| Неділя | Підготовка 2-3 drafts. | 2 threads + питання. | Stories recap. | Підсумок тижня. | Оновити KPI Dashboard. | Система перемагає натхнення. |
| Щотижневий review | Обрати 1 переможця LinkedIn. | Обрати 3 threads для розвитку. | Обрати 1 формат для повтору. | Зберегти 5 сторіз-ідей. | Оновити Experiment Log. | Повторювати те, що дає якісну реакцію. |
| Batching | 1-2 години на drafts. | Threads можна писати наживо. | Зняти 2-3 Reels блоком. | Stories наживо. | 30 хв аналітики. | Залишити місце для спонтанності. |
| Розподіл | 2-3 strong posts. | 20 posts/week. | 2-3 posts/Reels/week. | 10/day. | 1 weekly review. | Якість LinkedIn важливіша за кількість. |
