# Otake — продукт і позиціонування

> [!note] Статус
> Це продуктове знання з робочого періоду. Не використовувати як опис поточної зайнятості — див. [[Робота/Otake — досвід і висновки]].

## Що це

**Otake** — український SaaS-стартап (юридично **Otake Inc, Delaware**). Будує **design-first link-in-bio мікросайти** для креаторів і сервісних бізнесів.

Основний біль, який продукт закриває: у бізнесу або креатора є сильний візуальний бренд в Instagram, але зламані або generic «цифрові вхідні двері». Клієнт відчуває цей розрив.

## Правила бренду (не обговорюються)

- Назва — **Otake**. Велика O, без домену. Ніколи не «otake.io» у повідомленнях.
- Преміум-тариф пишеться як **pro plan** — з малої, жирним.
- Без P.S. у кінці повідомлень.
- Без зайвих знаків питання — вони створюють тиск.
- Без формально-бюрократичної мови («Шановний/а», «пропоную до розгляду»).
- **Тире — тільки одинарний дефіс ( - )**. Ніколи em dash.
- «ви» з малої літери в українських текстах.

## Ключові диференціатори

Проти Linktree / Beacons / lnk.bio / hoo.be / bio.site / Calendly:

| Фіча | Чому має значення |
|---|---|
| Повна візуальна кастомізація | кольори, шрифти, layouts, банери — сторінка виглядає як бренд, а не як шаблон |
| Apple Wallet інтеграція | у Linktree цього немає; для локального бізнесу — контакт зберігається після першого візиту |
| Вбудований booking | онлайн і офлайн; фоловер обирає слот, івент падає в календар власника |
| Перемикання режимів | Work / Creator / Side Hustle — одна людина, різні світи |
| Дашборд аналітики кліків | доказ цінності для рекламодавця креатора |
| QR / NFC шеринг | офлайн-міст |
| Кастомний URL | `otake.io/username` |
| Portfolio embeds | Figma, Dribbble, Adobe, Behance |
| Монетизація | цифрові продукти |

## Ціна

- **pro plan — $192/рік.**
- Амбасадорам дарується безкоштовно, довічно.
- Відомий сценарій знижки для існуючого користувача: -50%, $96 замість $192, промокод формату `USERNAME50`.

## Хто найкраще заходить (B2B-сегменти)

| Категорія | Чому підходить | Сигнал |
|---|---|---|
| Тату-майстри / приватні студії | преміум IG-бренд, майже порожній сайт, запис через DM | «DM to book», сайт на GoDaddy |
| Онлайн фітнес-коучі | Linktree як увесь хаб | Linktree в біо |
| Бутикові салони краси | сильний бренд засновника, чужий booking-портал | красивий IG + generic Vagaro/Meevo |
| Весільні фотографи/відеографи | розкидані по 5+ платформах | «link in bio for details» |
| Luxury event planners | сайт — забагато для першого кліку | активно продають з IG-біо |
| Makeup artists | кілька IG-акаунтів, немає хабу | два+ профілі |
| Pilates / yoga / wellness засновники | недовикористаний особистий бренд | «in high demand», 500+ контактів у LinkedIn |
| Real estate personal brands | розкидані між MLS, брокериджем і соцмережами | «LINK IN BIO» у постах |

## Де живе продуктова правда

- **Confluence, Sales Quick Reference** — актуальні ціни, диференціатори, скрипти заперечень, метрики. Ніколи не вигадувати цифри — брати звідси.
- **Confluence, Booking spec** — специфікація фічі бронювання.
- Деталі ID: [[Системи/Інструменти та інтеграції]].

## Правило точності

Кожна фіча, твердження і ціна в будь-якому матеріалі має походити з Confluence або з otake.io. Вигадана фіча в ТЗ для блогера коштує дорожче, ніж відсутня секція.
