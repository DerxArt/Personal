# Кваліфікація лідів

Фільтри застосовуються **до** того, як лід потрапляє в CRM. Профіль, що не проходить хоча б один — пропускається або логується з явною позначкою «не кваліфікований — причина».

## Жорсткі фільтри

| Критерій | Умова | Чому |
|---|---|---|
| Підписники | 2 000 – 50 000 (розширений діапазон скаута: 5K – 500K) | нижче 2K — мертві DM; вище 50K — обсяг діректу такий, що персональна відповідь малоймовірна |
| Engagement | лайки не менші за ~0.5–1% від підписників | нижче — накручена або мертва аудиторія |
| Активність | останній пост за останні 7 днів | інакше «Inactive — skip» |
| Відкритість до колаб | у біо є «collab», «DM for work», «business inquiries», «partnerships» або бізнес-емейл | **найсильніший предиктор відповіді** |
| Тип акаунта | особистий креаторський, не компанія/агенція/бренд-сторінка | |
| Не реклама | пропускати рілси з позначкою Ad / Sponsored | це не органічні креатори |
| Не мега-акаунт | пропускати верифікованих 100K+ | ймовірність відповіді дуже низька незалежно від інших метрик |
| Мова | англомовне біо/підписи за замовчуванням | налаштовується під кампанію |
| Приватність | тільки публічні акаунти | |

## Пріоритетний сигнал

**Конкурентний лінк у біо = найтепліший лід.** Людина вже показала готовність платити за подібний інструмент.

Що шукати:

**Link-in-bio:** `linktr.ee`, `beacons.ai`, `bio.link`, `bio.site`, `taplink.cc`, `later.com/linkinbio`, `lnk.bio`, `campsite.bio`, `stan.store`, `milkshake.app`, `carrd.co`, `sprout.link`, `solo.to`, `bento.me`, `koji.to`, `hoo.be`

**Мікросайт / портфоліо:** `framer.com`, `framer.website`, `webflow.io`, `notion.site`, `super.so`, `typedream.com`, `wix.com`, `squarespace.com`, `cargo.site`, `readymag.com`

**Booking / scheduling:** `calendly.com`, `cal.com`, `acuityscheduling.com`, `booksy.com`, `tidycal.com`, `zcal.co`

**Контакт / месенджинг:** `mssg.me`, `manylink.co`, `contact.me`

Власний домен (`yourname.com`) **не** вважається конкурентом.

Позначка в нотатках: `🔥 Використовує [назва]`.

## Статуси в CRM

Дві воронки; воронка визначається статусом.

- **Prospecting:** `new` → `contacted` → `followup` → `followup2` → `dead`
- **Sales:** `interested` → `talks` → `deal` → `active` → `done` / `lost`

Мапінг статусів після першого дотику:

| Ситуація | Статус |
|---|---|
| DM надіслано успішно | `contacted` |
| DM не пройшов (акаунт обмежує), warm-up зроблено | `contacted` |
| Переписка вже була без відповіді, зроблено лише warm-up | `followup` |
| Лід відповів будь-що | `interested` |
| Лід явно відмовився | `notint` / `dead` |

## Правило чесності даних

Ніколи не вигадувати кількість підписників, нішу, імʼя чи емейл. Якщо профіль не збагатився — лід зберігається з позначкою `manualInfoNeeded: true` і порожніми полями. Порожнє поле краще за вигадане.

Емейл не конструюється за патерном (`first.last@domain`) і не подається як знайдений. Якщо емейл у біо обрізаний — не вгадувати, позначити «email truncated — DM only».
